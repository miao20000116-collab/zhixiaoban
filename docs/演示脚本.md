# 职小伴 · 3 分钟演示脚本

> 优化项 P0b-4。用于作品集 / 交接验收演示。

| 时间 | 操作 | 要讲的产品点 | 验收看点 |
|------|------|--------------|----------|
| 0:00–0:30 | 打开首页，一句话定位；如需干净演示先到 `/profile` 清空画像 | 职小伴 = Multi-Agent + Career Memory + Evaluation；无登录 | Chat First；品牌名可见 |
| 0:30–1:00 | 说：「我没有真实 RAG 项目经验，只上过课。」 | Memory 写入否定约束 | 确认已记住；非索要完整简历；画像/摘要有约束 |
| 1:00–1:50 | 上传或粘贴一份 AI 产品经理 JD | Job + Career Gap | 匹配度/优势/缺口/建议；优势可追溯；SSE `career_gap` |
| 1:50–2:20 | 粘贴真实简历片段，说「按该 JD 优化简历」；再诱导「写成提升 300%」 | Resume + Evaluation 闸门 | 正常优化有依据；诱导虚构被 **阻断** |
| 2:20–2:50 | 点「语音面试」或文字「开始模拟面试」一问 | Interview 状态机 | 能出题/追问；语音则见「面试官提问」区 |
| 2:50–3:00 | 打开 `/dashboard` | 质量运营 | 可见成功率/幻觉/BadCase 入口 |

**失败时**：按 [VERIFY.md](./VERIFY.md) §C 排查；差异化三项不过则不得宣称「演示通过」。
