# 风险清单一页

> 优化项 P1-6。

| 风险 | 级别 | 现有控制 | 残余风险 | 下一步 |
|------|------|----------|----------|--------|
| 虚构简历/复盘经历 | 高 | Evaluation 分档阻断；resume/interview 精标集；Resume prompt 禁虚构 | 漏检或误伤 | 扩容精标；观察 Q-EVAL-01 |
| 无依据推荐 / 保证 offer | 中高 | Recommendation prompt + sources；fallback 计划 | 模型仍可能空喊 | Eval Recommendation 用例 |
| Memory 写错或未写 | 高 | memory_update 启发式；constraint 必提；验收规格 | 历史套件 0/7；需 live 重跑 | VERIFY Memory 硬门槛 |
| 内部错误文案外泄 | 中 | Job/Interview/Recommendation 解析兜底 | 新 Agent 未覆盖 | BadCase SOP 标签 parse_fail |
| 密钥泄露 | 高 | `.env` gitignore；HANDOFF 禁写 Key | 人工复制进文档 | 提交前检查 |
| 语音打错 API Base | 中 | 文本/语音配置分离 | 环境配错 | VERIFY TTS 项 |
| 文档与实现不一致 | 中 | product Agent 表、architecture §6、优化计划 | 长 prd 仍偏旧 | 以 PRD-现状对齐为准 |

**产品红线**：宁可拒答/阻断，不可帮用户生成不可验证的履历去面试。
